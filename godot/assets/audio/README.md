# Audio sources

# Audio in this directory has two sources. The original prototype effects are
generated by `godot/tools/generate_audio.py`; weather sounds are generated by
`art/scripts/generate_environment_media.py`. Eight dinosaur calls are adapted
from CaveboyTup's CC0 recordings via `art/scripts/build_dinosaur_audio.py`.
Source pages, license and checksums are recorded in `art/audio/CREDITS.md` and
`art/audio/sources/licenses.json`. No film or other game recordings are used.

`day`, `night`, `fire`, `generator`, `wind_breeze`, `wind_gale`, `rain`,
`jungle_day` and `jungle_night` loop with crossfaded boundaries. Repeated work,
combat and interface events rotate through deterministic transient variants, so
the gameplay bindings stay unchanged while frequent actions sound less exact.
The remaining files are short event sounds. Replace individual WAVs to improve
the sound design without changing gameplay event bindings.

Runtime: `scripts/sound.gd`. Bus controls: Master, Ambience, Effects; interface
feedback uses Master volume. Preferences persist to `user://audio.cfg`.
The listener follows the camera's ground focus. Distant and hidden gameplay
events are suppressed, and an output limiter prevents stacked sounds clipping.

Verification: `sh scripts/godot.sh --script res://tests/audio_test.gd` uses the
real audio driver, checks mixer samples, and records a preview to
`godot/captures/audio-preview.wav`. A nonzero mix does not by itself verify the
user's physical speaker or headphone output.
