目标是用户确认的魔兽争霸 III《侏罗纪公园》6.5。技术栈为 Godot 4、GDScript、原生可编辑 3D 场景。原网页项目仍保留。

当前为已接入独立 3D 资源的可玩版本，**尚未达到原版规则的一比一还原**。已补全开局资源返送和施工、可通行电门、战争迷雾，并导入候选原图的地形与布置坐标；在用角色、恐龙、树木和建筑已替换为原创 Blender 模型。已核对的规则来自本地 6.5 汉化修正版候选，该候选含附加作弊脚本，不能称作纯净官方版本。只读取布局和规则，未运行其 JASS，也未导入魔兽模型或贴图。

## 移动与指针反馈

新开局默认平滑跟随角色；空格或“归位”会持续跟随，F 切换自由视角。降低俯仰至近地角度或拉近镜头时也会自动恢复跟随；WASD / 方向键 / Shift + 中键仍可自由平移地图。旧存档保留保存时的跟随状态，按空格即可恢复。

悬停显示与目标对应的斧头、镐、施工锤、修理工具、准星等图标；点击有扩散标记，执行中显示目标和实际路线点。不可达或无法放置时显示红色反馈。详见 [实现与验证记录](../docs/development/movement-feedback.md)。

## 启动与编辑

双击根目录 `启动游戏.command`；可选标准生存（25 分钟 + 最多 5 分钟撤离）或保留原有刷新节奏的 45 / 60 / 80 分钟长局。开始界面支持继续或选择存档。

默认全屏启动，视野随屏幕比例扩展，避免宽屏两侧黑边并保持模型与 UI 比例。按 F10 打开设置，在“画面”中切换全屏/窗口，应用后 15 秒内确认；已保存的窗口选择会在下次启动时保留。原生显示回归覆盖 3840×2160 全屏及四种窗口比例，截图位于 `captures/display/`。

```sh
sh scripts/godot.sh
sh scripts/godot.sh --editor
```

也可在 Godot 项目管理器导入 `godot/project.godot`。本机使用官方 Godot 4.4.1，工具位于 `.tools/Godot.app`，不属于游戏源码。

## 当前可以玩什么

建造通路预警：绿色为可放置，红色为不可放置，黄色表示可能切断通路；黄色位置点击后会说明影响，确认前不扣费。移动受阻会尝试重新规划，无法恢复时提示原因；工作目标消失、维修完成或木材不足也有反馈。详见[营地通路与工作衔接](../docs/development/camp-flow-delivery.md)。

2026-09-20：左键选中建筑后，可点击下方“拆除”。确认框列出返还量，确认后立即恢复通路；返还建造投入的 50%，按剩余耐久折算并向下取整，免费帐篷不返还。撤离阶段新增前往 H 的按钮、贴地登机进度环及离开区域后的回退提示。详见[拆除与撤离反馈交付](../docs/development/demolition-extraction-delivery.md)。

声音已接入：启动提示、昼夜环境、脚步、采木/挖矿、施工、返送资源、建成提示、营火、发电站、电门、射击、电击、恐龙咆哮、受击及结算。右上角“声音”可调整总音量、环境和音效，支持静音和试听，设置会保存。当前为原创合成占位音效，不是原版录音或电影配乐。

1. 免费放置帐篷，幸存者走到工地施工。移动或停止命令会中断施工；右键未完成建筑可继续。升级实验室则自行计时。
2. 右键树木采木，初始每趟携带 1 木，到可到达的已完成帐篷后才计入库存；砍完会寻找附近可到达的下一棵树。没有帐篷时保留携带物并等待；右键帐篷也可手动返送。
3. 造营火，再造化石挖掘场；右键已完成挖掘场采金，同样需要返回帐篷。旧的预置无限化石点已退出正常开局。
4. 发展发电站、电栅栏、弓箭塔与电门。右键电门切换，耗时 5 秒；打开后可通行且不电击，门口有人或恐龙时不会强行关闭。右键受损建筑可消耗木材修理。
5. 探索地图：已探索地形留在记忆中，离开视野的恐龙从世界和小地图消失，也不能继续锁定攻击。树林和较高地面会阻挡视线；夜间幸存者视野缩小，营火和建筑提供视野。
6. 原图四区域边界已接入。沼泽对原版名单内的建筑从 70% 施工进度开始，冰原恐龙移动/攻击速度降低 30%，山地的塔、栅栏、电门有攻击及护甲加成。雨林魔法恢复等待魔法系统实现。
7. 幸存者和恐龙的待机、行走、攻击、死亡动画可在 AnimationPlayer 中编辑；恐龙死亡动画期间只结算一次击杀。
8. 每批定时刷新的恐龙中，一只会从营地周边 26–48 米的可通行位置出发，主动巡游到营地区域，其余在野外领地游荡。巡游目的地只在生成时记录一次，不会追踪玩家的实时位置；发现目标后主动进攻。树木和高地仍阻挡视线，失去目标后保留短时记忆并返回领地。随机刷新的恐龙避开幸存者、营地和当前可见区域。

## 场景与数据

- `scenes/main.tscn`：运行入口，引用 `scenes/reference_island.tscn`。
- `scenes/reference_island.tscn`：按候选 W3E / WPM / DOO 数据烘焙的可编辑场景。128×128 格、16,641 地面顶点、3,680 个已识别树木实例（2,991 个采集格）、410 个已识别岩石实例；树木、岩石坐标来自候选，模型为本项目制作。
- `scenes/island.tscn`：保留的首轮临时小岛，当前入口不再使用。
- `scenes/models/*.tscn`：独立 GLB 的包装场景。角色内的 Skeleton3D 和 AnimationPlayer 来自导入资产；在 Blender 源文件中编辑蒙皮与关键帧。原 `*_animations.tres` 仅保留为历史原型资料。
- `scenes/art_gallery.tscn`：独立模型和动作预览。
- `data/terrain.json`：提取后供客户端使用的高度、通行和布置数据。地面拾取通过真实三角网格碰撞，角色沿地表行走。
- `scripts/worker.gd`：工作命令、施工、携带、返送、采完换树、修理。
- `scripts/dinosaur_ai.gd`：有限感知、短时噪声、追击记忆、领地游荡、返回与反击；独立于音频播放。
- `scripts/vision.gd`：共享视野、探索记忆、地形遮挡与场景迷雾材质。
- `scripts/regions.gd`：原图准确区域矩形及施工加成名单。
- `scripts/terrain_data.gd`、`board.gd`：地形高度与导航。
- `scripts/session.gd`、`catalog.gd`：资源、电力、建造和升级规则。
- `scripts/world.gd`、`pawn.gd`：世界编排、战斗、输入和动画状态。
- `scripts/camera_rig.gd`：相对镜头平移、指数平滑、跟随、旋转与地形高度保护。
- `scripts/scenery.gd`、`shaders/`：现有场景的渲染装饰、风动与迷雾、水面、地面、营火和施工阶段；不修改原始地图数据。
- `scripts/forest_renderer.gd`：16 米空间分块的静态树木批量绘制，采完后的实例移除与索引维护。
- `scripts/pawn_visual.gd`：可配置动画名称、模型根节点、骨骼挂点、工具/携带物场景；玩法逻辑不依赖具体手臂节点路径。

研究证据与逐项参数：[6.5 开局核查](../docs/research/jurassic-park-6.5-opening.md)、[地图导入说明](../docs/research/jurassic-park-terrain-import.md)。
