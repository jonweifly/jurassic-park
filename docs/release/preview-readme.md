# 失落岛屿：生存营地 - 桌面内部试玩

macOS：解压后打开 `LostIsle-Preview.app`。本包来自 Godot 4.4.1 官方 macOS 导出模板，并采用本机临时签名；没有 Apple 开发者签名或公证。首次启动如被 macOS 阻止，可在“系统设置 → 隐私与安全性”查看提示。

Windows：将 `LostIsle-Preview.exe` 和同目录的 `LostIsle-Preview.pck` 保持在一起，双击 EXE 启动。Linux：将 `LostIsle-Preview.x86_64` 和同目录的 `LostIsle-Preview.pck` 保持在一起，给可执行文件执行权限后运行。Windows/Linux 由 Godot 4.4.1 官方模板导出，但尚未在目标系统实测。

开始界面可新建单机或局域网双人游戏。F10 打开画面和键位设置；F5 保存，F9 选择存档。存档、声音和画面设置写到 Godot 用户数据目录，不写回 App。项目更名后只会复制旧画面、键位及声音设置；旧参考地图存档保留在原目录，不能在新岛屿加载。

**仅限内部试玩。** 主游戏使用独立生成的原创岛屿，但美术来源、商店权益和目标平台兼容性尚未全部复核。请阅读随包的 `发行前审计.md`，不要将本包直接上传游戏平台或商用。
