## 动作与玩法衔接

- 躯干、颈部、肘、膝和尾部使用权重过渡；手、工具、下颚和脚有独立骨骼。
- 行走采用离线两段腿骨求解，脚掌保持稳定朝向，轮流支撑；步频按实际移动距离和动画步幅调整。导航继续拥有位移，无 Root Motion 叠加。
- 伐木/挖矿触点仍为 1.10 秒，施工触点仍为 0.65 秒，经济结算由 Worker 负责，动画不重复增加资源。
- 骨骼网格、手部挂点和携带挂点都通过 `pawn_visual.gd` 接入；玩法没有重新绑定占位手臂节点。
- 地图布局、资源格、返送、建筑占地、寻路、战争迷雾、恐龙感知及出怪节奏保留。模型自身不另加一套与棋盘冲突的物理阻挡。

## 材质、环境与性能

- 统一探险营地配色，共享 1024² 颜色、粗糙度和微表面法线图集。保留 UV、MikkTSpace 切线及稳定的模型轴向。
- 地表、水面、昼夜光照与树叶风动继续工作；补充地图蕨类、营火烟雾、动态火焰和余烬。雪地限制高亮，避免白昼过曝。
- 提高方向光阴影图分辨率并调整偏移，兼顾地形自阴影和人物接地。
- 3,680 棵树仍使用 984 个空间批次承载 14,720 个源部件；采完树木会实际移除对应实例。近景使用完整树冠，远景/大缩放使用独立低细节模型，并保留切换滞回。远离镜头覆盖范围的批次停止绘制。
- GLB 网格和动画总计约 **2.42 MB**，共享纹理约 **3.42 MB**。纹理外置在 `godot/assets/materials`，分发时须与 GLB 一起保留。来源文件、导入缓存和截图不计入这两个数字。

性能数字见 [原始采样](../../godot/captures/delivery/forest-production.json)。本机 Apple M5、Godot 4.4.1、GL Compatibility、1280×800，在固定演示营地采样；包含阴影与迷雾通道。此采样不能外推为全地图或其他设备的稳定 FPS。最终修改阴影设置后的数据以该 JSON 与 [渲染日志](../../godot/captures/delivery/tests/render.log) 为准。

在项目根目录运行：

```sh
sh scripts/build-art.sh
sh scripts/godot.sh --headless --script res://tests/production_assets_test.gd
sh scripts/godot.sh res://scenes/art_gallery.tscn
```

重建使用本地 Blender 4.5.3 LTS、固定版本 glTF Transform 4.5.0 和 Godot 4.4.1。GLB 保持未压缩几何以兼容当前客户端，使用去重、切线生成、共享纹理和 LOD 控制成本。旧 `godot/tools/generate_models.py` 是历史占位生成器，不应用来覆盖本轮包装场景。

## 仍存在的限制

- 本轮是原创程序化制作的风格化低多边形美术。面部、衣物褶皱和恐龙肌肉没有达到专业美术逐件雕刻的精度；没有表情骨骼、布料模拟和电影级细节。
- 离线步态保证平地接地，尚无实时坡面脚部 IK、攀爬、翻越或根据目标高度动态修正工具触点。棋盘格移动和大体型寻路仍沿用原有体系。
- LOD 使用滞回切换，没有交叉淡化；近距离刻意来回缩放仍可能察觉树冠密度变化。
- 冰原树的积雪以叶面颜色表现，尚非单独堆积雪层几何。区域地形仍以原布局数据为基础，未逐片雕刻悬崖和河岸。
- 全套回归和短时原生采样已完成，尚未在 Windows、低端 GPU 或持续一整局 80 分钟上做实机性能验收。
- 现有音效仍是合成音效。原版规则中的未实现项继续以项目 README 为准；本轮没有把美术交付描述成全游戏一比一完成。
