# 现有视角跟随与鼠标反馈

按用户澄清，本轮保持现有俯视 / 低角度镜头与右键命令操作，优化持续跟随；没有新增第一人称模式。

## 镜头行为

- 新开局默认持续跟随幸存者，一次移动命令后，镜头逐帧平滑跟随，无需再次点击。
- 空格和“归位”现在回到并持续跟随角色；Home 恢复默认角度、缩放并跟随。
- 从高角度降到 44°以内，或从远景拉近到 24 以下时，自动恢复跟随。保留原有角度、缩放边界与地形高度保护。
- WASD、方向键或 Shift + 中键可平移地图并进入自由视角；F 切换跟随。右上角显示“跟随中 / 自由视角”。旋转与缩放本身不会打断已有跟随。
- 继续沿用随帧时间计算的指数平滑。窗口失焦时不再响应镜头键盘输入。
- 存档格式不变，保留玩家保存时的跟随选择。旧存档如果处于自由视角，按一次空格即可进入持续跟随。

## 鼠标与目标反馈

新增 11 张原创 SVG 图标。鼠标悬停时根据实际操作显示移动箭头、砍树斧头、采金镐、施工锤、修理工具、攻击准星、资源返送、电门及调查图标；配有文字说明。治疗命令也有目的地医疗标记。

悬停与右键命令统一通过 `world.context_at()` 判断目标，避免图标与实际操作各自维护一套规则。隐藏恐龙不会显示攻击图标，未发现的设施不泄露调查类型，未知树木仍按探索移动处理。可见恐龙在重叠位置优先被选为攻击目标。

点击后显示扩散动画，执行中保留带操作图标的目标标记；路线点读取角色当前真实路径，绕路或重新规划时同步更新。移动命令标记实际可达终点，采集、施工等标记交互对象。X 停止命令时清除路线及旧目标动画。不可达位置显示红色禁止图标和失败反馈；建造时显示放置是否有效及具体原因。

菜单、暂停、窗口失焦和镜头拖动时恢复系统鼠标，操作界面不会被自定义指针遮住。路线点最多绘制 24 个，只在已探索区域显示；悬停寻路结果按目标、角色所在格和导航版本缓存，最迟 0.15 秒刷新，不改变模拟随机数或玩法噪声。

## 验证

Godot 4.4.1 / macOS Apple M5 / GL Compatibility。

- 新增 **35 项移动与指针检查**：一次命令后角色与镜头持续移动、低视角跟随、手动平移、归位/缩放/俯仰切换，各种图标与实际命令一致，不可达位置、迷雾、界面覆盖、焦点丢失及存档兼容。
- 新增 **8 项原生窗口输入事件检查**：通过 Viewport 事件分发执行真实地形拾取、右键移动、目标动画、连续跟随、点击日志按钮、菜单后的世界输入拦截和 Esc 关闭。
- **575 项检查、7 组持续遭遇全部通过**。10 局原有策略完整回归为 **7 次撤离、3 次正常战斗失败**，物流路线 3/5、防御路线 4/5，与前一轮结果一致。没有放宽测试断言或给整局机器人额外资源。
- 四张原生渲染截图检查移动前后、斧头目标和攻击反馈；发现提示文字可能覆盖底部 HUD 后，改为自动翻到指针上方。

## 重复箭头修正

用户截图中的两个箭头来自移动 SVG 自带的双箭头，以及目标标记复用整张鼠标图标。现将移动指针改为单一箭头，移动目标仅保留定位圈；其他目标使用 `assets/interaction_icons` 中的独立工具图标。点击扩散动画只画定位圈，不再重复绘制图标。

本次按范围复跑移动反馈 35 项与原生输入 8 项，并重新渲染截图检查指针和目的地分离时的效果。原生输入夹具在窗口初始化结束后明确恢复游戏状态，以避免开始测试时被自动暂停拦截；正式游戏的失焦暂停保持不变。未重复执行未受此次视觉修正影响的整局回归。

## 精简交互提示

鼠标图标由 44×44 缩至 32×32（约缩小 27%），目标工具图标由 32×32 缩至 24×24，热点随缩放同步调整。正常移动不显示文字或背景提示框；无法到达、无效放置等异常原因继续显示。其他操作提示改用 13 号字体和更紧凑的边距。

所有鼠标与目标图标以 SVG 三倍分辨率导入并生成 mipmaps，在固定 UI 尺寸下平滑采样；斧头采用更简单、对比更清晰的刀头和带描边木柄。移动与点击规则不变。
