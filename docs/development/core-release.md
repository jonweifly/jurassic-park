# V0.5 核心体验迭代

本轮范围为上一轮评估的 P0；P1 地图任务、AI 分工和内容扩充及 P2 长线内容后续迭代，不混作已完成。

## 设计边界

- 保留 Godot 原生客户端、现有原创模型、地图、地形和局部感知机制。
- 原有 45 / 60 / 80 分钟作为长局模式保留；新增 25 分钟标准生存。新增研究、治疗和节奏均为本项目设计，不宣称是原图 6.5 已核对规则。
- 标准单局：落脚与返送 → 开采黄金 → 电力防线 → 实验室投资 → 救援预警与撤离。物流优先与防御优先都应有收益。
- 存档是完整单局快照，读档重建世界；保留工作、携带物、施工、电门、科技、恐龙感知、迷雾、随机状态与救援计时。载入后暂停，避免玩家未准备好即受攻击。
- 不通过扩大恐龙全图感知来制造难度，不以玩家研究进度动态抵消成长收益。

## 执行与验收

1. 工程：改动前源码压缩备份；新增集中式状态格式与回归入口。当前无 Git 仓库，不虚构版本提交。
2. 成长：可操作科技面板、真实消耗与研究时间、断电/实验室损毁暂停、容量和效率/防御收益、营地付费治疗。
3. 节奏：标准模式阶段性敌人组成、明确阶段目标、预警与撤离威胁、数量上限；保留长局遭遇回归。
4. 基础功能：手动存档、三份轮转自动存档、继续、失败读档、损坏回退和版本校验。
5. 交互：工作与库存信息、研究/治疗条件、暂停模态、加载与退出反馈；保持既有操作。
6. 验证：既有规则/世界/AI/遭遇/美术/音频回归；新增持久化、研究、节奏集成测试；原生 UI 截图复核。

自动化回归不代替真人完整单局的乐趣和数值验收。最终报告记录真实执行结果及尚未验证的内容。
