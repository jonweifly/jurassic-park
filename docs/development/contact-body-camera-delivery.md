# 动作接触、体型通行与近景遮挡

2026-09-19。承接探索内容变化阶段，完成这一轮运行时动作与通行表现。继续使用现有独立 GLB、骨骼与 PBR 材质；没有更改已确认的小指针、普通移动提示或低角度跟随方式。

## 本轮实现

### 工作动作与坡面接地

- 幸存者使用显式配置的生产骨架进行双骨骼解算，替代资源和其他骨架不被隐式绑定。动画仍负责完整的预备、挥动、回收和携带动作。
- 脚部采样真实地形高度和法线，保留原步行动画的抬脚高度；下坡时有限降低视觉骨盆，分别校正双腿和脚掌。只修改渲染姿势，不改变游戏坐标、移动速度、导航或存档位置。
- 砍伐、采矿、建造和修理会在碰撞允许时走近工作面。目标距离分别为 1.34、1.5、1.7 米；不能安全靠近则保留原来的可达工作位置，不强行穿入障碍。
- 工具即将落下时，手腕与手臂根据目标近表面进行有限校正。采矿额外前倾脊柱，使镐尖更接近低矮的化石表面。过远目标不会拉长骨骼、移动角色根节点或无限扭转关节。
- 木屑、碎石和工作声从实际工具头位置产生。采集结算仍由原工作计时器负责，动作解算不发放资源、不改变背包上限和施工费用。
- 修复弹道完全竖直或起终点重合时的朝向问题。

### 恐龙体型与导航

- 幸存者、幼小迅猛龙、迅猛龙、幼年霸王龙、成年霸王龙的平面通行半径分别为 0.30、0.32、0.48、0.82、1.12 米。它们是服务于通行的躯干近似，不是尾巴、头部和每个骨骼的精确碰撞形状。
- 移动分段检查圆形身体与阻塞格的边界，大体型寻路使用扩张后的障碍网格；成年霸王龙不会尝试挤进两米宽的单格走廊。
- 建造、开门、拆除和清树引起地图修订后，体型导航缓存会更新。老档位置若处于新增的身体边界内，允许向外脱离，禁止继续深入，不瞬移角色。
- 建筑相邻路线补上连续靠近段，使大体型依然能进入原有三米攻击距离。包括“已在最近网格中心、寻路没有新的格点”的边界情况。
- 随机刷新的大体型恐龙检查完整脚印，追击、巡逻、绕行和返巢调用均传递自己的体型。不改听觉、视距、攻击间隔和伤害。

### 建筑与岩石遮挡

- 从原有树冠淡化扩展到岩石、营地建筑、脚手架和静态探索设施。只有位于角色与相机之间、靠近角色投影的一小片表面会淡化，避免整栋设施消失。
- 保留原材质的颜色、法线、粗糙度、金属度、高光和剔除模式；不转换角色蒙皮、透明或无光照特效。
- 迷雾计算与淡化在同一材质中完成，避免原来的迷雾覆盖层把缺口重新盖住。淡化不改视野数据、敌人可见性、碰撞或建筑可选状态，阴影仍使用完整物体。

## 可复现验证

```sh
python3 scripts/test-core.py --full-session --audio
sh scripts/godot.sh --script res://tools/capture_contact.gd
sh scripts/godot.sh --script res://tools/profile_contact.gd
```

专项测试包含：窄通道体型差异、绕行每一段的完整通行空间、开门缓存失效、老位置脱离、霸王龙真实攻击建筑、四个朝向完整步行周期的坡面支撑脚及骨骼连接、三种工具触点与重复计算不累积、原生建筑迷雾材质顺序，以及竖直/零长度弹道。原有经济、存档、遭遇、探索和操作测试继续运行。

截图由 Godot 4.4.1 / OpenGL Compatibility 原生窗口渲染。动作细节截图使用检查镜头；正常游玩视角见 `gameplay-overview.png`。岩石与建筑对比图通过同一场景开关淡化参数生成，不是两次不同布局的游戏。部分设施为隔离渲染行为的临时测试实例，不用于证明建造费用或关卡平衡。

性能脚本在真实岛屿上放置 42 只不同体型恐龙，采样 180 次模拟与渲染；临时提高测试角色生命以保持场景存活。这是本机压力采样，不是普通战斗平衡或跨平台帧率证明。

### 最终结果

- 22 组测试入口均通过，共 **947 项检查**；另有 **7 组主动遭遇场景**和 **20 局真实经济整局机器人流程**通过功能门槛。原事件安排与随机探索组合各为 6 次撤离、4 次正常失败；不以“所有机器人必须胜利”作为通过标准。
- 七组遭遇的首次受击约 81–88 秒，清除首批敌人后的第二批受击约 154–162 秒。该专项会提高角色生命以观察多批遭遇，不能当作普通角色的生存能力证明。
- 20 局整局流程沿用真实库存、生命、造价、研究和资源返送，没有为了通关赠资源或生命。与上一轮样本结果不同，说明体型和停靠位置会影响实际战况；样本不足以确定真人难度或胜率。
- 最终弹道修复后补跑 `contact,world`。整局原始日志保留了修复前的竖直弹道警告；补测包含零距离及竖直弹道边界。
- Apple M5、1280×800、Compatibility：42 只恐龙压力场景中，模拟更新中位数 **0.838 ms**、P95 **1.962 ms**、最大 **2.301 ms**；包含强制绘制与等待的迭代中位数 **30.434 ms**、P95 **34.669 ms**，884 次绘制调用。该迭代时间不是纯 GPU 耗时，也不直接当作游戏 FPS。
- 相同压力场景关闭新增遮挡材质后，迭代中位数 31.484 ms、P95 35.779 ms。这组短采样没有显示新增遮挡材质带来明显额外开销，不是普遍性能保证。
- 压力场景会输出一次 macOS OpenGL `GLD_TEXTURE_INDEX_2D ... unloadable` 诊断。关闭新增材质仍复现，截图未观察到贴图缺失；具体来源尚未定位，留在兼容性清单中，不作“渲染日志完全无警告”的结论。

不可变验证副本、整局数据、原生日志和性能数据均归档在 `godot/captures/contact/`。

## 限制与后续

- 接触面仍按资源类型估计，尚未对每棵树、每栋建筑的三角面进行精确工具碰撞。极端斜坡、太远或过高目标会受到关节校正限幅；不是完整全身 IK。
- 通行采用现有格网和圆形身体近似；尚未增加单位之间的物理挤压/推开，也不包含长尾、脖颈的逐骨骼碰撞。
- 局部淡化沿用树冠的网点风格，放大检查时能看到点阵。跨平台画质、低配置和长时间运行仍属于发布打磨阶段。
- 后续按既定顺序继续环境与声音层次、撤离演出，再做安装包和发布验证。
