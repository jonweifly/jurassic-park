# 双人合作实施计划

第一版保留 Godot 原生客户端，使用 ENet，通过局域网或虚拟局域网地址加入，最多两人。无公网匹配、中继、账号和房主迁移。

1. 房间与身份：开始界面的创建/加入入口、房间口令、协议核对、连接超时、人数限制、离开与重连。
2. 权威模拟：房主统一结算资源、建造、恐龙 AI、伤害、科技和撤离；客户端只提交意图。每位幸存者保持独立角色、指令、携带物及镜头。
3. 世界同步：初始地图状态、动态角色与动画、树木库存、建筑与门方向、科技、击杀、天气、战斗反馈。客户端不重复扣费或计算伤害。
4. 合作规则：共享库存/营地/视野，独立生命；倒地后可由队友就近救起，全员阵亡失败。存活成员共同进入撤离区。多人增压仅作用于联机。
5. 会话边界：暂停与模态面板协调，房主退出明确终止房间；短暂掉线保留同一角色。首版独立保存合作局，不能把合作局误写成普通单机存档。
6. 验证：两个独立 Godot 进程实测连接、独立移动与采集、资源与建造一致、门与拆除、攻击双方、重连、非法指令、断线及胜负；原有单机回归；原生 UI 截图。

验收以真实双进程测试为准。外部公网/虚拟局域网及跨平台体验须与朋友的实际设备另行验证，不能以本机测试替代。
