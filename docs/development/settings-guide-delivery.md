# 设置与生存手册交付

2026-09-19。本轮承接移动与指针调整，继续第 1 阶段的操作体验、引导与单机基础功能。后续内容扩充、美术音频和发布打磨仍需推进，不作为全部阶段完成。

## 本轮完成

| 功能 | 使用方法 | 行为 |
| --- | --- | --- |
| 游戏设置 | 默认 F10；开始/暂停菜单也有入口 | 打开时暂停，关闭后返回原状态；应用后保存 |
| 画质 | 流畅 / 均衡 / 精细 | 流畅关闭阴影、抗锯齿与装饰草丛；均衡为 2×抗锯齿/2048 阴影；精细保留原有 4×抗锯齿/4096 阴影 |
| 显示 | 全屏、垂直同步、30/60/120/不限帧率 | 全屏变化先预览，15 秒内确认才保存；超时或关闭自动还原 |
| 镜头 | 平移、旋转、缩放速度 0.5–2 倍；反转中键上下俯仰 | 保留低角度持续跟随和手动平移退出跟随的控制方式 |
| 路线提示 | 路线点开关 | 可隐藏行走路线点，仍保留目标图标和失败反馈 |
| 键位 | 27 项主要操作可改为单键 | 冲突提示；Esc 取消录入；恢复默认先放入草稿，应用后生效 |
| 生存手册 | 默认 F1；开始/暂停菜单也有入口 | 当前目标、操作速查、生存知识；主动查看，不强制弹窗 |
| 上下文引导 | 按营地实际进展给出下一步 | 帐篷→采木/营火→黄金来源→供电→防御→实验室→研究与撤离 |

设置保存在 Godot `user://preferences.cfg`，独立于单局存档。配置类型错误与非法键位有默认回退；磁盘保存失败会还原本次更改并说明原因。音量继续通过原有“声音”面板保存。

引导读取实际游戏状态，不额外保存一套教程进度。它识别未完工建筑、背包未入库、返送阻塞与资源缺口；按钮走现有建造/升级/移动命令，不赠送资源、不跳过前置、不重复收费。存档恢复、建筑损毁后再次打开会重新计算目标。

同步清理了界面中的旧固定快捷键文本；面板切换保持互斥和暂停状态。临时通知到时清空，延续已确认的小指针与简洁画面。

## 验证

统一入口：`python3 scripts/test-core.py --full-session --audio`。

新增设置/引导状态检查以及原生窗口输入测试，覆盖：配置加载与重启、类型/冲突回退、未应用草稿、保存失败还原、真正的全屏窗口切换及超时回退、暂停冻结、跨面板切换、改键后的实际命令和界面、正常客户端启动加载设置、画质与导航/RNG隔离、引导各主要进度以及存档共存。

原生输入通过 Godot Viewport 派发鼠标/键盘事件，走实际 Control 与游戏输入链；这不是操作系统级硬件点击测试。截图来自 Godot 原生 OpenGL 窗口，在 1280×800 和 1440×900 下检查布局、滚动区域与按钮可达性。

**最终结果：641 项检查全部通过，7 组遭遇场景通过；10 组整局自动试玩均通过功能门槛，7 次撤离、3 次正常战斗失败（物流路线 3/5，防御路线 4/5）。音频混音检查通过。没有通过额外生命、资源或降低恐龙强度来改写失败结果。**

最终结果与日志见 `godot/captures/preferences/verification.json` 及同目录 `tests/`。
