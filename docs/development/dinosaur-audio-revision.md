# 恐龙吼叫素材替换

2026-09-19。试玩指出上一轮纯合成声音像闷沉低鸣，缺少恐龙吼叫感。本轮更换声音来源，而非仅提高音量或再次叠加低频。

- 采用 CaveboyTup 的 CC0 素材 **T-rex Calls**（鳄鱼、狮子、麋鹿素材制作）与 **Small Dino Raspy Calls**（马喷鼻素材制作）。来源、原文件、页面和校验和保存在 `art/audio/sources/`，授权说明在 `art/audio/CREDITS.md`。
- 从 T-rex 音轨后半段选用有爆发和中高频的吼叫，避开前半段低沉咕噜声；剪辑连接尾部喘息，适度提速、去除次低频、提升存在感、软压缩和响度匹配。没有加入新的正弦低音层。
- 成年霸王龙两条约 5.2/5.4 秒长吼；幼年霸王龙使用较短、较高的变体。迅猛龙由嘶哑喷气声配短喉音组成，小型迅猛龙更短促。
- 全局叫声间隔覆盖实际音频长度，重击也不再绕过正在播放的吼声；防止多只大型恐龙重叠形成低频团。保留已有距离衰减、左右声像、环境音压低、音量和暂停逻辑。
- 原环境生成器不再生成恐龙声音，避免后续重建天气音频时覆盖本轮素材。独立生成入口为 `art/scripts/build_dinosaur_audio.py`，依赖两个解码后的 WAV 和 numpy。

专项执行 `environment,dinosaur_ai,environment_audio,audio`，包括原生音频混音、左右声像、静音、暂停、满通道优先级、非重复播放和 AI 回归。实际混音检查通过不能代替真人对声音自然度的评价。本轮只修改音频素材和叫声调度，没有重跑 20 局经济回归，也不把上轮结果冒充本轮验证。

试听 `godot/captures/dinosaur-audio/comparison.wav` 顺序为：旧霸王龙 → 新霸王龙 → 迅猛龙 → 小型迅猛龙，中间留空，音量经过匹配。`native-mix-preview.wav` 为更新素材后的 Godot 原生混音录制，包括全部恐龙变体与天气声音。

当前不需要引入 FMOD 或 Wwise：现有 Godot 混音总线、声像、优先级及天气动态混音已能支持此阶段。将来出现复杂自适应配乐、规模更大的分层声音设计或专职音频设计师协作时，再评估中间件。高质量拟音素材与剪辑仍是本次问题的关键。

这些音效是基于动物素材设计的恐龙声音，不声称是史前恐龙的真实录音，也不是影视原声。本轮尚未经过用户试听确认。
