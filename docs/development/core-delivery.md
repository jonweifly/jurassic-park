# 核心体验迭代交付（P0 主功能）

本轮在原有 Godot 客户端和独立 3D 美术基础上，落地了成长、治疗、标准单局、撤离和存档续玩。它是上一轮规划的 P0 核心功能迭代，不是 P1/P2 全部内容完成或正式版认证。

## 可以直接体验的变化

| 内容 | 本轮实现 | 操作 |
| --- | --- | --- |
| 标准单局 | 25 分钟生存 + 最多 5 分钟撤离；前期迅猛龙，中期幼年霸王龙，后期成年霸王龙；保留 45/60/80 分钟长局 | 开始界面选择 |
| 科技成长 | 背负 I–III（容量 2/3/4）、精制工具（采集及施工 +35%）、防线强化（伤害 +30%、所受伤害 -20%）、营地医疗、救援电台 | 基础建筑 → R 升级实验室 → T 科技 |
| 研究条件 | 真实金木消耗、研究时间、前置研究、单项目运行；停电/实验室损毁暂停，恢复后继续 | 科技面板显示条件和进度 |
| 营地治疗 | 前往可到达帐篷，每秒 1 金恢复 10 生命，医疗研究后恢复 25；可随时中断 | H 治疗，X 或新命令中断 |
| 撤离收尾 | 2 分钟前预警；电台可提前救援；标准模式在 H 区累计守住 12 秒登机，离开时进度缓慢下降；撤离仍有局部遭遇 | 北侧 H 停机坪 |
| 战斗衔接 | 咬击接触时判定距离与伤害，可利用前摇离开；射击立即朝向目标；目标消失后停止旧追击路线 | 沿用右键攻击 |
| 工作可靠性 | 开关电门保留原工作命令；停止清理工作恢复状态；携带资源与入库保持分离 | 右键与 X |
| 存档与重试 | 手动、三份自动轮转、上次手动备份、选择历史记录、损坏记录回退；读档后暂停 | F5 保存，F9 选档 |
| 单机反馈 | 分阶段目标、治疗及研究条件、缺电/濒死/救援提示、结算统计、切换应用自动暂停、保存并退出 | HUD 与 Esc 菜单 |

科技、治疗和标准模式属于本项目新增设计，不宣称是原版 6.5 已核对规则。原有地图、原创模型、骨骼资源、局部感知范围、迷雾与长局刷新间隔保留。

## 存档范围及恢复

存档覆盖库存、科技及研究、施工、电门切换、挖掘场储量、树木消耗、人物位置/路线/动作、工作及携带物、恐龙生命/感知/待结算攻击/死亡状态、迷雾、随机数状态、刷新计时、救援与登机进度、镜头与昼夜。恐龙用独立稳定编号重建攻击目标，不能沿用旧场景的运行时实例编号。

文件采用版本与地图标识、长度限制、SHA-256 完整性校验及数据结构检查；先写临时文件，再替换存档。手动覆盖前保留上一份有效记录。继续按钮选择最近的有效记录，F9 可主动选择较早的存档。

存档位置是 Godot `user://saves`，本机对应：

`~/Library/Application Support/Godot/app_userdata/侏罗纪公园 · 生存营地/saves`

自动保存每 120 秒游戏时间执行，暂停时不计时；演示、截图和脚本测试不向正式存档写入。临时粒子、声音播放游标不序列化，载入后由游戏状态重新驱动。

## 验证

Godot 4.4.1 / macOS Apple M5 / GL Compatibility。

- 既有 279 项规则、场景、AI、移动镜头、美术管线、资源和实际音频混音检查。
- 新增 86 项核心体验检查：研究消耗/暂停恢复/收益、治疗、施工与资源返送存档、尸体不重复结算、随机状态、攻击前摇、撤离和登机状态、损坏回退等。
- 新增 10 项真实场景重载检查：加载后暂停、恢复路线/镜头、恢复原库存、存档选择面板、选择手动记录而非较新的自动记录。
- 原有 7 组持续遭遇回归，确认首轮和后续恐龙继续主动接近。
- 10 组完整自动试玩：交替使用物流优先与防御优先，实际采集、施工、研究、战斗、后撤、治疗和撤离，不额外授予资源或生命；最后两组不研究电台，用于覆盖完整 25 分钟计时。
- 原生 OpenGL 截图复核开始界面、营地、科技、暂停、存档选择与撤离，包含 1440×900 与 1280×800 的逻辑布局。

功能检查与胜负观察分别记录。完整试玩的功能门槛是经济不出现负值、恐龙数量不超过上限、流程能进入胜利或正常失败，以及两条投资路线都有成功撤离样本；每组胜负、生命、研究及库存完整保留。普通死亡不等于引擎或流程错误，自动角色的胜率也不能代表真人难度。

本轮最终结果：**375 项检查全部通过，7 组持续遭遇通过；10 组整局自动试玩均满足功能门槛，8 次撤离、2 次正常战斗失败。** 物流优先和防御优先各 4/5 次撤离；两组不修电台、完整等待 25 分钟的流程均成功撤离。另两次失败分别发生在后期防守与撤离阶段，已保留原始结果，没有增加测试角色资源/生命或削弱敌人来抹除失败。

最终执行结果：[verification.json](../../godot/captures/core/verification.json)；单局详细记录：[full-session-report.json](../../godot/captures/core/full-session-report.json)。

复跑：

```sh
python3 scripts/test-core.py --full-session --audio
sh scripts/godot.sh --script res://tools/capture_core.gd
```

## 工程和后续边界

- 修改前已备份脚本、测试、项目配置及说明到 `.tools/backups/pre-core-20260919.tgz`。当前目录没有 Git 仓库，本轮没有虚构提交或远程版本。
- 新增 `save_store.gd` 集中处理持久化，`session_director.gd` 管理单局节奏；没有重新生成或覆盖已完成的 Blender/GLB 资源。
- 尚未组织 5 名新玩家引导测试、完成 Windows/低配置设备认证或原生 80 分钟性能长测。不能据自动化检查宣称所有 P0 产品验收已完成。

- 数值和真人操作舒适度仍需持续调整，尤其成年霸王龙的压迫感、撤离准备和新手开局负担。没有把场景、美术或既有玩法降低到仅供测试通过的版本。
