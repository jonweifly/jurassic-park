# 侏罗纪公园 6.5 原图候选与静态规则核查

核查日期：2026-09-15。仅下载数据并读取 MPQ、JASS 文本和物编数据；未运行地图、外来游戏程序或安装器。下面规则是这个特定文件的事实，不自动代表所有叫 6.5 的版本。

## 来源与真实性边界

- 找到[西西软件园 6.5 增强汉化版页面](https://www.cr173.com/soft/427952.html)，页面日期 2017-03-01，体积 3.2 MB；正文称优化地形、大量汉化。页面下载脚本公开指向 [ZIP 数据文件](https://cz.197942.com/tcy/zlj65zqhh.zip)。成功下载 ZIP，唯一成员为 `侏罗纪公园6.5增强汉化版.w3x`。
- 文件头与 WTS STRING 1 均为 **侏罗纪公园增强版 V6.5 汉化修正版**，不是 6.5.2，也不是通过改文件名冒充的 6.3。
- ZIP SHA256：`d9612e0eed2c5ac2d13e7eb769d9d318b0d607ec6e7bd6fa81e6947bf753d619`。
- W3X SHA256：`64d883c68d5195ada51ce3d0bcce50efde45c97dbd6c3590b63beffc3e17ecf7`；3,353,317 字节。
- WTS STRING 1363 自述：使用 PerfectlyInsane 开源模板；作者 SaMmM；“V6.5 是作者官方最终版本”。这是地图内自述，尚未找到作者本人发布页来独立证实。
- **这个下载文件含额外作弊代码**：JASS 中出现 `Auto Cheated by Jheb93`（约 2830 行）、`Cheatz`（3354 行）、资源修改命令和作弊触发初始化（15481 行附近）。因此只能认定是**公开流传的 6.5 汉化修正版候选**，不能称为已经验证的纯净官方原图。原图只用于只读参考，不应把脚本整体移植到客户端。
- [3DM v6.5.2](https://dl.3dmgame.com/patch/205301.html) 是明确不同的小版本，未下载，未混入下面数值。

## 已生成可校准数据

`reference/warcraft-6.5/` 包含原 ZIP、W3X 及只读提取文件。`parse_objects.py` 可重新生成：

- `objects.json`：单位、科技、道具、技能的所有物编修改字段。
- `units-buildings.json`：164 个单位/建筑定义，保留原始 ID、底层模板 ID、名称、价格、时间、需求等。
- `research.json`：科技名称、费用、等级、耗时和需求。
- `periodic-spawns.json`：定时生成触发、周期表达式、单位和原始函数正文。
- `terrain-summary.json`：地形尺寸、原点、地砖编号。

**JSON 中 null 表示此地图未覆写，需继承 Warcraft 基础数据，不能当作 0。** 特别是英雄血量、移动速度、部分建筑黄金费用和科技等级等。目前没有 Warcraft 原生 SLK 数据，也没有运行时测量。

## 开局与采集

- 玩家 0–6 在地图中心分别放置一个 `H02Q` 幸存者，玩家 0 坐标 `(170.7, 221.3)`。证据：`war3map.j:15807`。
- 开局初始化函数 `GC` 将七名玩家黄金设置为十六进制 `$A`，即 **10 金**；由开局触发调用。证据：`war3map.j:5325`、`4810` 附近。
- 未找到开局显式设置木材的语句；不把这一点直接等同于已验证的 0 木。
- 幸存者物编：100 初始魔法 / 100 最大魔法；基础力量 5、敏捷 1、智力 1。血量和移动速度有基础英雄继承，不凭字段缺失推算。
- 幸存者建造表：帐篷、营火、化石挖掘场、发电站、电栅栏、电门、哨塔、`o003`、基础建筑、科技建筑。物编 `H02Q.ubui`。
- 化石挖掘场 `n000` 的说明明确为挖化石卖钱的 **金矿**，需求帐篷与营火。资源返送技能说明指向最近的帐篷，见 `war3map.wts` 相关资源返送条目。
- `I005` 是“欢乐大餐（有玩具）”，物编价格 10 金 / 10 木。地图存在给幸存者补发此物品的事件；**未把这些事件擅自当成无条件开局物品**。

## 时间、撤离与胜负

- 当前文件提供 **45 / 60 / 80 分钟**时长选择；对应救援倒计时为 2700 / 3600 / 4800 秒。默认选择为 60 分钟。证据：`war3map.j:5115`、`5126`、`5223`。
- 时长选择后先播开场音效并触发坠机事件，再开始救援倒计时；倒计时并非地图加载瞬间开始。
- 直升机出现后开始 **300 秒，即 5 分钟**撤离计时；随机选择十个预置区域之一，并清除落点附近障碍。证据：`war3map.j:10041`。
- 玩家必须上直升机，`J[player]` 为登机标记。结算同时检查 `I[player] == 0` 和 `J[player] == 1`，胜利与困在岛上分别判定。证据：`war3map.j:10266`、`10324`、`10375`。`I` 也关联幸存者死亡/替代单位逻辑，不能只按存活时间胜利。
- 6.5 更新说明明确新增幸存者变巨人技能、移除变身药水、增加难度与游戏时长。WTS STRING 1359。

## 四大地形

地图地形二进制为 **129 × 129 个顶点 / 128 × 128 个格子**，原点 `(-8192, -8192)`，Warcraft 每格 128 世界单位。

WTS STRING 3471 明确写出（文字规则，尚未逐一核对全部区域触发）：

| 区域 | 方位 | 地图内说明 |
|---|---|---|
| 山地 | 右上 | 建筑护甲 +3、炮塔攻击 +50%；霸王龙领地 |
| 沼泽 | 右下 | 建筑速度提高 70%；苍蝇、蚊群多，一般武器难以消灭 |

| 雨林 | 左下 | 幸存者魔法恢复提高、体力果；成年恐龙多 |

## 恐龙生成与行为

- 存在按难度开启不同触发器的多物种独立周期生成，生成位置多为全图可玩区随机点，**并不是八个固定波次**。
- 例如普通难度分支启用 `EV/NV/CV/fV/hV/JV/IV/OV`。`EV` 每 160 秒生成 2 个 `o001` 与 1 个 `o007`；`NV` 每 160 秒生成 1 个 `o000`；`CV` 周期取 70–90 秒，生成 2 个 `o004` 与 1 个 `o008`。其他分支见 `periodic-spawns.json`。
- 这里 `GetRandomReal` 在定时器注册时执行，不能擅自写成每一轮重新随机周期。
- 存在每 15 / 20 秒取随机敌方单位、取玩家单位位置并下达命令的 AI 触发。函数 `xm/rm/am` 与 `em/om/im` 是入口，后者使用订单 `$D000F`。还存在恐龙技能、被攻击事件、死亡事件以及结束阶段移动速度调整。尚未完整翻译所有行为条件，因此不将其概括成完全还原的 AI。
